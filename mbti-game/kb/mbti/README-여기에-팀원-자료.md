# MBTI 지식베이스 폴더 — 팀원 자료 넣는 곳

이 폴더의 파일들이 S3에 올라가 "게임 종료 후 Q&A 챗봇"의 답변 근거가 됩니다.

## 사용 방법

1. 팀원이 가진 MBTI 자료를 이 폴더에 복사합니다.
   - 가능한 형식: `.md` `.txt` `.pdf` `.docx` `.html` `.csv` — Bedrock Knowledge Base가 모두 읽습니다.
   - 파일 이름은 한글이어도 됩니다. 내용이 잘 나뉘도록 제목(#, ##)을 달아두면 검색 품질이 좋아집니다.
2. 폴더 전체를 S3 버킷의 `mbti/` 경로에 업로드합니다 (실습 가이드 3단계).
3. Knowledge Base에서 "동기화(Sync)" 버튼을 누르면 새 자료가 벡터로 변환됩니다.
   - 자료를 추가·수정할 때마다 다시 Sync 해야 반영됩니다.

## 이미 들어 있는 것

- `mbti-기본지식.md` — 기본 지식(4축 · 8속성 · 16타입 요약). 게임에 내장된 것과 같은 내용의 시작 자료입니다. 팀원 자료가 쌓이면 챗봇 답변이 그만큼 풍부해집니다.

## 팁

- 자료에 "궁합", "직업 추천", "연애 스타일", "공부법" 같은 주제가 있으면 플레이어가 그런 질문을 했을 때 바로 근거로 쓰입니다.
- 챗봇은 자료에 없는 내용은 "모른다"고 답하도록 설계되어 있습니다. 답변 폭 = 자료 폭.
