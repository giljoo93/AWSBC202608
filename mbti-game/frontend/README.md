# 프론트엔드 — 웹 게임 프로토타입

백엔드 없이 브라우저에서 **8분기 완주 → MBTI 결과 → Q&A**까지 전부 동작한다.
하향식(프로토타입 우선) 개발이라, 화면을 먼저 확정하고 기능은 뒤에 붙인다.

## 실행

ES 모듈을 쓰므로 `file://`로 열면 동작하지 않는다. 정적 서버가 필요하다.

```bash
cd mbti-game/frontend
py -m http.server 8765
# → http://127.0.0.1:8765
```

## 화면 설계 — 비주얼 노벨 관례를 따른다

레퍼런스 조사 결과, 텍스트 게임 UI의 근간은 **화자의 유무로 두 종류의 텍스트를 나누는 것**이다.

| | 서술 (NVL) | 대사 (ADV) |
|---|---|---|
| 화자 | 없음 | 명찰로 표시 |
| 글꼴 | 명조체 | 명조체 (더 크게) |
| 배경 | 어두운 패널 + 왼쪽 금색 선 | 금빛 패널 + 따옴표 |

스토리 원문(`storyboard.json`)에는 화자 메타데이터가 없다.
`js/narrative.js`가 큰따옴표와 등장인물 이름 목록으로 화자를 추론한다.
간접인용(`레온은 "…하자"고 제안한다`)은 대사로 떼지 않고 서술 안에 인라인으로 남긴다.

### 그 밖의 게임 연출

- **장 전환** — 암전 → 「제 3 장 · 첫 실전」 제목 카드 → 본문. 장마다 화면을 비운다
- **배경 크로스페이드** — 장면마다 배경 일러스트가 부드럽게 교체된다
- **등장인물 입상** — 대사가 나오면 그 인물이 무대에 서고, 서술로 돌아가면 어두워진 채 남는다
- **진행도** — 점 8개. 전투 분기는 마름모로 구분해 "무게"만 전달하고 점수는 노출하지 않는다
- **판정 연출** — 8번째 선택 후 회전하는 문양 + "차원문이 당신을 읽고 있습니다"
- **백로그** — 지난 기록 전체 보관 (장이 넘어가도 사라지지 않음). `기록` 버튼 / `Esc`로 닫기
- **결과 카드** — 축별 대비 막대. 축 합이 3점이라 비율이 4가지뿐이라 퍼센트 게이지보다 대비가 낫다

## 파일 구조

파일별 상세 설명은 **[`FILES.md`](FILES.md)** 참조 (역할·의존 관계·언제 손대야 하는지).

| 파일 | 역할 |
|---|---|
| `index.html` | 마크업 뼈대 (배경 레이어 · HUD · 로그 · 컨트롤 · 백로그) |
| `css/style.css` | 전체 스타일 (배경 레이어 · 입상 무대 · 말풍선 · 결과 카드) |
| `js/data.js` | **자동 생성** — `finalplan/gen-frontend-data.py` 로 만든다. 직접 수정 금지 |
| `js/narrative.js` | 서술/대사 파서 (화자 추론) |
| `js/sprites.js` | 인물 실루엣 SVG — 이미지가 없을 때의 대역 |
| `js/api.js` | 데이터 계층. `USE_MOCK` 플래그 하나로 목 ↔ 실서버 전환 |
| `js/render.js` | DOM 조작 전담. 데이터 출처를 알지 못한다 |
| `js/app.js` | 상태 머신 (idle → playing ×8 → judging → result → qa) |
| `assets/ART-DIRECTION.md` | **이미지 통일 규격서** (스케치 방식 · 팔레트 · 파일 규격) |
| `test/playthrough.mjs` | 헤드리스 플레이스루 테스트 |
| `FILES.md` | **파일별 설명문** |
| `index.legacy.html` | 이전 단일 파일 참고 구현 (보존용, 배포 대상 아님) |

## 테스트

브라우저 없이 8분기를 실제로 클릭해 완주하는 jsdom 테스트.

```bash
py finalplan/build-single-file.py     # dist/index.html 생성 (테스트 대상)
cd mbti-game/frontend/test
npm install                            # jsdom
npm test
```

검증 항목: 타이틀 → 8분기 진행 → 장 제목 → 진행도 → 판정(ABBAABBA → ISFJ)
→ 축 승자와 판정 일치 → Q&A 왕복 → 백로그 누적.

## 백엔드 붙이기

`js/api.js` 첫머리 한 줄만 바꾸면 된다.

```js
export const USE_MOCK = false;   // ← true 에서 false 로
```

목과 실서버가 **같은 응답 폼**(`../API.md` 계약)을 반환하므로
`render.js` / `app.js` 는 수정할 필요가 없다.

계약과의 차이 하나: 응답에 `background` 필드를 추가로 기대한다.
서버가 안 주면 `backgroundForStep()`이 장면 번호로 폴백하므로 **없어도 깨지지 않는다.**
`background`에는 팔레트 3색과 장 제목(`title`)이 들어 있다.

## 이미지

배경 10장(`assets/bg/`)과 등장인물 6명(`assets/cast/`)이 **생성 완료**되어 있다.
Bedrock `stable-image-control-sketch` 에 구도 스케치를 넣어 만들었다 —
방식·팔레트·재생성 규칙은 `assets/ART-DIRECTION.md`.

**코드 수정 없이 교체할 수 있다.** `render.js` 가 실행 중에 파일 존재를 확인해서,
있으면 이미지를 쓰고 없으면 CSS 그라디언트·SVG 실루엣으로 자동 폴백한다.

이미지를 바꾸고 싶으면 `assets/bg/` `assets/cast/` 에 **같은 이름으로 덮어쓰면** 된다.
새로 생성해야 한다면 요금이 발생하므로 `assets/ART-DIRECTION.md` 7절을 먼저 볼 것.

때문이다 (`finalplan/frontend-render-draft.md` 5절).
