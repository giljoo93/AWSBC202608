# 이미지 아트 디렉션 — 통일 규격서

배경 10장 + 인물 6명이 **한 사람이 그린 것처럼** 보이게 하기 위한 규격서.
이미지는 Bedrock 으로 이미 생성되어 있다. 이 문서는 **어떤 규칙으로 만들었고
다시 만들 때 무엇을 지켜야 하는지**를 설명한다.

> 생성 스크립트는 **의도적으로 저장소에 넣지 않았다** — AWS 요금이 발생하는 코드라
> 모르고 실행하는 사고를 막기 위해서다. 필요하면 kdy 에게 요청할 것.


생성 완료 — `assets/bg/` 10장, `assets/cast/` 6장.

---

## 1. 왜 "스케치 → 그림" 방식인가

이 AWS 계정에서 쓸 수 있는 이미지 모델은 **Stability 편집 계열뿐**이다.
순수 text-to-image 인 Nova Canvas 는 LEGACY 로 차단돼 있다.

```
✗ amazon.nova-canvas-v1:0        LEGACY — "Access denied ... marked by provider as Legacy"
✓ us.stability.stable-image-control-sketch-v1:0     스케치 + 프롬프트 → 그림
✓ us.stability.stable-image-remove-background-v1:0  인물 배경 제거
```

그래서 **구도 스케치를 코드로 그려서** 넣는다. 결과적으로 이쪽이 낫다 —
"하단을 비워달라"고 프롬프트로 부탁하는 대신 스케치로 **강제**할 수 있기 때문이다.

```
생성 스크립트가 PIL 로 회색조 스케치 생성
   ↓  (광원 위치 · 지평선 높이 · 덩어리 배치 · 비워둘 전경)
control-sketch 모델이 그 구도대로 채색
   ↓
인물은 배경 제거 → WebP 변환
```

스케치만 따로 뽑아 눈으로 확인할 수 있다(호출 없음 · 무료).
결과가 마음에 안 들면 **프롬프트보다 스케치를 먼저 고친다.**

## 2. 절대 규칙 (배경)

| # | 규칙 | 어떻게 강제하는가 |
|---|---|---|
| 1 | **화면 하단을 비운다** | 스케치의 `floor` 아래를 어둡게 눌러 둠 |
| 2 | **광원은 한 곳** | 스케치의 `light` 밝은 덩어리 하나 |
| 3 | 얼굴이 보이는 인물 없음 | 네거티브 프롬프트 + 원경 구도 |
| 4 | 글자·로고 없음 | 네거티브 프롬프트 |
| 5 | 어둡게, 채도 낮게 | 공통 스타일 문구 |
| 6 | 가장자리 어둡게 | 공통 스타일 + 코드의 `.bg-vignette` |

말풍선과 선택지가 화면 아래를 덮으므로 **1번이 가장 중요하다.**

## 3. 절대 규칙 (인물)

| # | 규칙 | 이유 |
|---|---|---|
| 1 | **배경은 완전히 투명** | 장면 위에 세워야 하므로 |
| 2 | 허리 위, 프레임 안에 다 들어오게 | 잘리면 무대에서 어색함 |
| 3 | 살짝 안쪽을 향한 3/4 각도 | 화면 중앙(플레이어)을 바라보는 구도 |
| 4 | **역광 림라이트** | 어두운 배경 위에서 인물이 떠 보이게 |
| 5 | 림라이트 색 = 그 인물의 `accent` | `js/data.js` 의 CAST 와 맞춰야 통일됨 |

주인공(플레이어)의 이미지는 만들지 않는다 — 플레이어 자신이기 때문.

## 5. 파일 규격

| 항목 | 배경 | 인물 |
|---|---|---|
| 생성 크기 | 1280 × 720 | 768 × 1152 |
| 포맷 | WebP (불투명) | WebP (**알파 채널**) |
| 목표 용량 | 170KB 이하 | 240KB 이하 |
| 경로 | `assets/bg/<key>.webp` | `assets/cast/<key>.webp` |

배경은 어차피 어둡게 깔리고 위에 베일이 덮이므로 **화질보다 용량이 우선**이다.
현재 16장 합계 약 1.3MB.

## 6. 코드가 이미지를 찾는 방식

**코드 수정이 필요 없다.** `js/render.js` 가 실행 중에 파일 존재를 확인한다.

- 파일이 있으면 → 그 이미지를 쓴다
- 없으면 → CSS 절차적 배경 / SVG 실루엣이 그대로 남는다

그래서 이미지를 **한 장씩 교체해 넣으면서** 확인할 수 있다.
단일 파일 빌드(`dist/`)에서는 `build-single-file.py` 가 data URI 로 인라인한다.

## 7. 다시 만들 때

**요금이 발생하는 작업이다. 반드시 계정 소유자와 먼저 합의할 것.**

> 생성 스크립트는 **의도적으로 저장소에 넣지 않았다** — AWS 요금이 발생하는 코드라
> 모르고 실행하는 사고를 막기 위해서다. 필요하면 kdy 에게 요청할 것.

사용한 모델과 단가 (us-east-1):

| 모델 | 용도 | 단가 |
|---|---|---|
| `us.stability.stable-image-control-sketch-v1:0` | 스케치 + 프롬프트 → 그림 | $0.07 / 장 |
| `us.stability.stable-image-remove-background-v1:0` | 인물 배경 제거 | $0.07 / 장 |

전체(배경 10 + 인물 6×2회)를 다시 만들면 22건 = **약 $1.54**.

조절 가능한 값:

- **스케치** — 결과가 별로면 프롬프트보다 이걸 먼저 고친다. 구도가 그림을 결정한다
- **control_strength** (기본 0.55): 스케치를 얼마나 충실히 따를지. 0.3 자유 / 0.8 충실
- **seed**: 같은 시드는 같은 결과. 마음에 드는 시드를 기록해 둘 것
