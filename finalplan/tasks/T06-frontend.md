# T06 — 프론트엔드 (정적 챗 UI)

선행: T05 · 담당: **프론트 팀원** (JSON 계약: `mbti-game/API.md`)

역할 분담: 백엔드가 `API.md`에 요청/응답 JSON 폼을 고정 — 프론트 팀원은 그 폼만 보고
자유롭게 렌더링 구조화. `frontend/index.html`은 계약대로 만든 참고 구현.

## 목표

S3+CloudFront에 올릴 정적 파일. 챗봇 형태: 내레이션 말풍선 + 선택지 버튼 2개,
결과 후엔 자유 입력창으로 전환.

## 산출물

- `frontend/index.html` — 단일 파일 (인라인 CSS/JS). 프레임워크·빌드 도구 없음

# ponytail: 바닐라 단일 html — 화면 1개짜리 챗 UI에 React/빌드 불필요. 화면 늘어나면 그때 분리.

## 화면 흐름

```
[시작하기] → start 호출
내레이션 표시 → 버튼 A/B → choice 호출 → 반복 ×8
done 응답 → MBTI 카드(4글자 + 점수 바 8개) + 결과지 → 입력창 활성화 → chat 호출
```

## 작업 내용

1. `API_BASE` 상수 1개 — 배포 시 EC2/CloudFront 주소로 교체하는 유일한 지점
2. fetch + async, 로딩 중 버튼 비활성화 (중복 선택 방지)
3. 모바일 뷰포트 대응 (max-width 컨테이너)
