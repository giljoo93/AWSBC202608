## 1. 화면 상태 4개

한 페이지 안에서 상태만 전환한다 (라우팅·페이지 이동 없음).

```
idle ──[시작하기]──> playing ──×8──> judging ──> result ──> qa
                        └─ 에러 ─> fatal (재시작 안내)
```

| 상태 | 트리거 | 화면 |
|---|---|---|
| `idle` | 최초 진입 | 타이틀 + 시작 버튼 |
| `playing` | `start` 응답 | 내레이션 + 선택지 2개 (×8 반복) |
| `judging` | 8번째 선택 직후 | **판정 연출 화면** (아래 3-6 참조) |
| `result` | `done:true` | MBTI 카드 + 결과지 |
| `qa` | 결과 표시 완료 | 자유 입력창 활성 |

## 2. 레이아웃

```
┌──────────────────────────────────────┐
│  배경 이미지 레이어 (고정, 크로스페이드)  │
│ ┌──────────────────────────────────┐ │
│ │  어둠 오버레이 rgba(0,0,0,.45)     │ │
│ │ ┌────── 헤더 (고정) ───────────┐ │ │
│ │ │  차원문 너머      ●●●○○○○○   │ │ │
│ │ └──────────────────────────────┘ │ │
│ │                                  │ │
│ │   ┌────────────────────────┐     │ │
│ │   │ 내레이션 말풍선          │     │ │  ← 로그 영역
│ │   └────────────────────────┘     │ │     (스크롤)
│ │            ┌──────────────┐      │ │
│ │            │ 내 선택       │      │ │
│ │            └──────────────┘      │ │
│ │                                  │ │
│ │ ┌────── 컨트롤 (하단 고정) ─────┐ │ │
│ │ │  [ A. 먼저 다가가 말을 건다 ] │ │ │
│ │ │  [ B. 물러나 관찰한다      ] │ │ │
│ │ └──────────────────────────────┘ │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

- 컨테이너 `max-width: 560px`, 중앙 정렬. 모바일 우선.
- 배경은 `position: fixed` + `object-fit: cover` — 로그가 스크롤돼도 배경은 안 움직인다.
- 선택지는 **하단 고정**(인라인 아님). 모바일 엄지 접근성 + 로그 스크롤과 분리.

## 3. 상태별 화면

### 3-1. idle — 타이틀

```
        ◈  차 원 문  너 머  ◈
     여덟 번의 선택이 당신을 말한다

        [  여정을 시작한다  ]

   ⚠ 새로고침하면 처음부터 시작됩니다
```
세션이 서버 메모리에만 있으므로 **경고를 시작 전에** 노출한다.

### 3-2. playing — 진행

- 내레이션 말풍선: 좌측 정렬, 반투명 다크, `white-space: pre-wrap` (개행 옴)
- 내 선택 말풍선: 우측 정렬, 강조색
- 선택 즉시 두 버튼 `disabled` + 고른 쪽 하이라이트 → 중복 클릭·실수 방지
- 선택은 되돌릴 수 없음 (undo 없음)

### 3-3. 로딩 — ★ 이게 없으면 체감이 무너진다

LLM 호출이 2~5초 걸린다. 그 동안 화면이 비면 "멈췄나?"가 된다.

```
 ┌──────────┐
 │  ● ● ●   │   ← 타이핑 인디케이터 말풍선을 먼저 띄우고
 └──────────┘      응답이 오면 그 자리에서 교체
```

### 3-4. 진행도 — 점 8개

```
 ●●●○○○○○     "분기 3 / 8" 텍스트보다 남은 양이 직관적
```
전투 분기(가중치 2점)는 점 모양을 다르게 줄지 논의 필요 → **미정**.

### 3-5. 내레이션 등장 연출

한 글자씩 타이핑은 3~5문장이면 답답하다. **문장 단위 페이드인**(0.15s 간격)으로 하고,
화면을 탭하면 즉시 전체 표시(skip). `prefers-reduced-motion`이면 연출 없이 즉시 표시.

### 3-6. judging — 판정 연출 ★ 신규 제안

8번째 선택 후 결과지 생성이 **가장 긴 LLM 호출**이다 (근거 8개 + KB 청크 → 긴 출력).
일반 로딩 점 3개로 버티기 어렵다.

```
        ◈ 차원문이 당신을 읽고 있습니다 ◈
              ( 회전하는 문양 )
```
전체 화면 오버레이 + 배경을 엔딩 이미지로 크로스페이드하며 대기.

### 3-7. result — MBTI 카드

축 합계가 항상 3점이라 비율은 **1:2 / 2:1 / 3:0 / 0:3 네 가지뿐**이다.
가로 게이지 바보다 **양쪽 대비 막대**가 읽기 쉽다.

```
 ┌────────────────────────────┐
 │         I S F J            │
 │  E ▭▭▭▭▭▭▮▮▮▮▮▮▮▮▮▮▮▮ I    │
 │  S ▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮ N    │  ← 3:0
 │  T ▭▭▭▭▭▭▮▮▮▮▮▮▮▮▮▮▮▮ F    │
 │  J ▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮ P    │
 └────────────────────────────┘
   [ 결과지 본문 — 긴 텍스트 ]
```
카드는 등장 시 스케일업 + 막대는 왼쪽부터 차오르는 애니메이션.

### 3-8. qa — 자유 질문

하단 컨트롤이 선택지 버튼 → 입력창 + 전송으로 전환.
질문/답변도 같은 말풍선 컴포넌트를 재사용한다.

### 3-9. 에러

`res.ok === false`면 서버가 준 `detail`을 그대로 보여준다.

```
 ⚠ 세션이 없습니다. 게임을 다시 시작해주세요.
        [ 처음부터 다시 ]
```
세션 소멸(서버 재시작·새로고침)이 정상 시나리오이므로 **재시작 버튼은 필수**.

## 5. 시각 방향

- 톤: 이세계 판타지 — 어두운 배경 위 **금색 강조**, 보조로 보라
- 타이포: 제목 세리프(또는 장식체), 본문 고딕. 한글 웹폰트는 용량이 크므로 **본문 1종 + 굵기 2개**로 제한
- 배경 이미지 11장 위에 항상 오버레이가 깔리므로 **텍스트 대비는 배경과 무관하게 보장**된다
- 모서리 둥글게, 말풍선은 반투명 + `backdrop-filter: blur()`

## 6. 접근성 / 반응형

- 새 말풍선 영역에 `aria-live="polite"`
- 키보드: `A`/`B` 키로 선택, `Enter`로 전송
- `prefers-reduced-motion`: 페이드·타이핑·크로스페이드 전부 끔
- 대비비 4.5:1 이상 (오버레이 농도로 확보)
- 320px 폭에서도 선택지 문구가 2줄까지 안 깨지게
